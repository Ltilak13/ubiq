# Review domain terminology

1. When meanings, relationships, or context boundaries need clarification, use
   /domain-modeling if it is installed. Read that skill before continuing.
   Supply the repository, relevant source evidence, disputed meanings, and
   permitted edit scope.
2. When the skill is unavailable, inspect the glossary and relevant code directly.
3. Test proposed meanings and relationships with concrete scenarios. Ask the
   owner to resolve competing meanings that the evidence cannot settle.
4. Record agreed definitions and unresolved questions within the permitted edit
   scope. Reuse established definitions where the meaning is unchanged.
